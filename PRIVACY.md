# ToggleBay Privacy Policy

ToggleBay is published by Sufficient Systems.

ToggleBay does not include advertising, analytics, tracking SDKs, user accounts, or cloud synchronization. The app does not request the Android `INTERNET` permission.

ToggleBay stores its configuration locally on the device. Data leaves the app only when the user explicitly invokes an export or share action, or when Android itself mediates a system control or permission flow the user requested. Android backup/device-transfer behavior is limited by the app's backup rules, which exclude transient capability tokens and generated share archives.

ToggleBay uses Android permissions and system settings only to provide controls the user invokes or enables. Some controls may open Android settings or permission screens because modern Android versions no longer permit direct app control. Permissions can be revoked through Android settings, although doing so can disable the related feature.

ToggleBay is an independent restoration of the open-source Power Toggles project. It is not affiliated with or endorsed by the original developer.

Original Power Toggles code is Copyright (c) 2015 sunnygoyal and is used under the MIT License included in `LICENSE.md`.

This policy describes the repository release behavior. Any future release that adds network services, analytics, advertising, accounts, or other data handling must update this policy and the corresponding Google Play Data safety disclosures before publication.
