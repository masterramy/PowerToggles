# ToggleBay

ToggleBay is an independent restoration and modernization of the open-source Power Toggles Android project. It provides configurable home-screen and notification controls for common device and system actions while preserving the project's widget-first workflow on current Android releases.

## Independent project

ToggleBay is published by **Sufficient Systems** under the independent package ID `app.sufficient.togglebay`. It is not affiliated with or endorsed by the original Power Toggles developer, and it does not reuse the historical Play listing or public package identity.

The original Power Toggles source is Copyright (c) 2015 sunnygoyal and is used under the MIT License. See `LICENSE.md` for the complete license text.

## Features

The restored project includes configurable home-screen widgets, notification controls, folders, import/export, icon and appearance customization, and the surviving control set supported by the current publication branch. Modern Android restrictions are handled through public APIs and system-mediated settings or permission flows where direct control is no longer available.

## Privacy

ToggleBay has no built-in ads, analytics, tracking, accounts, or cloud synchronization, and the publication source requests no Android `INTERNET` permission. Configuration is local to the device unless the user explicitly exports or shares it. See `PRIVACY.md` for the full policy.

## Release status

This repository contains the independently restored source and publication-readiness QA. A green repository build or test run is not evidence that a Google Play production release has been signed, submitted, or published.
